答题锁屏守护 · 安装到电视（傻瓜版）
=====================================

【最快的方式：让豆包/其他 AI 帮你装】
  电脑上打开豆包电脑版 → 切到「Agent 模式」→ 把 发给豆包的一句话.txt 里的内容
  整段复制发过去，按它说的做就行。

【自己动手：双击一个文件】
  1. 把这整个 tools 文件夹拷到电脑上（和 txhlock_v3.0.apk 放一起也行）
  2. 双击「一键安装.bat」
  3. 如果提示找不到电视，按窗口里的 4 步在电视上打开 ADB 调试
  4. 看到「安装完成」就好了

【电视上必须打开的一次性开关】
  · ADB 调试：设置 → 关于 → 产品型号连点 5~7 次 → 返回 → 开发者选项 → ADB 调试
  · 无障碍保底：设置 → 无障碍 → 答题锁屏 → 打开（安装器会自动开，没开就手动开）
  · 自启动：设置 → 应用 → 答题锁屏 → 自启动 → 打开（小米电视必须开）

【装完怎么用】
  · 电视桌面打开「答题锁屏」，家长密码默认 1234
  · 在设置里改：单次看多久、连对几题、孩子年级、题型
  · 想验证：点「立即锁定测试」，答对 3 题能解锁就正常

【常见问题】
  Q: 提示「签名不同，不能覆盖」
  A: 电视上装过别的签名版本。为了不丢设置，安装器不会自动卸载。
     在电视上：设置 → 应用 → 答题锁屏 → 卸载，再重新运行安装器。

  Q: 提示「找不到电视」
  A: 确认电脑和电视连的是同一个路由器（不是手机热点）；
     确认电视上「ADB 调试」已打开；再运行一次。

  Q: 装完主页键还是能回桌面
  A: 设置 → 无障碍 → 把 答题锁屏 关掉再打开一次。

【安全提醒】
  ADB 调试开着时，同一个 WiFi 里的任何设备都能控制这台电视。
  装好后建议回到 设置 → 开发者选项 → 关掉 ADB 调试。以后升级再打开。
