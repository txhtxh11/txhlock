【一句话 · 让豆包把 txhlock 装到电视上】

怎么用：
1. 电脑打开豆包，切到「Agent 模式」（能自己动手操作电脑的那个，不是普通聊天）
2. 把下面整段发过去，不用改任何东西
3. 它会自己找电视、自己装、自己开权限，不懂的地方会来问你，照实回答就行

━━━━━━━━━━ 复制这一段 ━━━━━━━━━━
帮我把家里的小米电视装上「答题锁屏」，并配置好，让孩子看满时间必须答题才能继续看。
请直接运行这个安装器（Windows PowerShell，它会自动找电视、装应用、开无障碍、保持常亮）：

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://cdn.jsdelivr.net/gh/txhtxh11/txhlock@v4.0/tools/install.ps1 -OutFile \"$env:TEMP\txhlock-install.ps1\"; & powershell -NoProfile -ExecutionPolicy Bypass -File \"$env:TEMP\txhlock-install.ps1\" -NoPause"

我是小白什么都不懂，需要我配合的地方直接问我，不要用术语。
电脑和电视连的是同一个 WiFi；电视是小米电视，Android 4.3。
如果脚本说找不到电视，请一步一步告诉我遥控器点哪里（设置 → 关于 → 产品型号连点 5~7 次 → 开发者选项 → ADB 调试）。
装完告诉我成功没有，并提醒我关掉 ADB、打开自启动、允许悬浮层。
如果提示「签名不同不能覆盖」，不要卸载，先问我。

━━━━━━━━━━ 它卡住 / 一直问你要电视 IP 时补发 ━━━━━━━━━━
补充说明：
- 电视 IP 我不知道，安装器会自动扫描局域网里开着 5555 端口的设备，那台就是电视；
  扫到多台它会自己选小米/电视设备，选错了你告诉我。
- 安装包下不动就换这个（一样能下，国内不翻墙可用）：
  https://ghfast.top/https://github.com/txhtxh11/txhlock/releases/download/v4.0/txhlock_v4.0.apk
- 电脑上没有 adb 不用管，安装器会自己装。
- 电视会弹「允许 USB 调试吗」，选「始终允许」→ 确定。
- 如果报签名冲突或空间不足，停下来告诉我，不要自己卸载重装，否则我的设置会丢。
━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━ 装完记得（三步，漏了等于白装）━━━━━━━━━━
1. 关调试：设置 → 开发者选项 → 关掉「ADB 调试」（开着时同 WiFi 谁能控制这台电视）
2. 开自启动：设置 → 应用 → 答题锁屏 → 自启动 → 打开
3. 开无障碍：设置 → 无障碍 → 答题锁屏 → 打开（安装器一般会自动开好）
4. 开悬浮层：设置 → 应用 → 答题锁屏 → 显示在其他应用上层 → 允许（4.3 安装即授权，6.0+ 需要手动允许）
   然后打开答题锁屏，输密码 1234 → 点「立即锁定测试」验证一下
