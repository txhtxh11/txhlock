=================================================
  txhlock 使用说明（小白版）
  不用懂技术，照着做就行
=================================================

这个软件是干嘛的？
------------------
让孩子看电视时，每隔一段时间就自动锁屏，用遥控器
做对几道题，才能继续看。防止孩子一直看电视不休息。


【第一步】把软件装到电视
--------------------------
1. 把电脑桌面上"答题锁屏守护"文件夹里的
   txhlock.apk  拷到一个U盘
2. U盘插到电视上
3. 电视上打开"文件管理器"（一般在"应用"里能找到）
4. 找到U盘里的 txhlock.apk，点它，选"安装"
5. 如果电视提示"不允许安装"，就打开：
   设置 → 安全 → 允许安装未知应用
6. 装好后，电视桌面上会出现一个叫 txhlock 的图标


【第二步】把题目放进电视
--------------------------
1. 把  小学一年级题库模板.txt  也拷到那个U盘
2. 在电视文件管理器里新建一个文件夹：
   内部存储 → Download → 新建文件夹，名字叫 txhlock
   （最后路径是：内部存储/Download/txhlock/）
3. 把 txt 文件复制进这个 txhlock 文件夹
4. 打开电视上的 txhlock 应用
5. 点"重新加载题库"，看到"已加载"就成功了


【第三步】开始用（默认已经开启）
----------------------------------
- 孩子看电视，到时间会自动锁屏出题
- 用遥控器 左右方向键 选答案，按 OK 键 确认
- 连续答对 3 题就解锁，可以继续看
- 答错一题，就要从头重新开始


想调整设置？
------------
打开电视上的 txhlock 应用：
- 单次连续观看：看多少分钟锁一次（默认20分钟）
- 连续答对题数：答对几道才解锁（默认3题）
- 题型：勾选要考的（口算/认字/古诗/英语）
- 修改家长密码：改4位密码


家长自己直接进去
----------------
- 锁屏的时候，按遥控器【菜单键】
- 输入4位密码（默认 1234）就能直接进


常见问题
--------
- 电视不锁屏？ 打开应用，看"监控开关"是不是"已开启"
- 题目还是旧的？ 放好txt后，要点一下"重新加载题库"
- 密码是多少？ 默认 1234，也可以在设置里改
- 想换二年级的题？ 把二年级的txt也放进 txhlock
  文件夹，应用会自动一起用
